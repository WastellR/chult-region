**An animated map pack compatible with Tomb of Annihilation - or any jungle-themed campaign of your own.**

![Screenshot](https://github.com/WastellR/chult-region/Screenshot_1.png)

The module contains:
- One hexcrawl map of Chult, with four animated variants (more coming soon).
- A custom UI for more conveniently managing the hexcrawl. Roll weather, navigation and encounters with just a couple of clicks.
- Animated maps automatically adjust to match current weather settings.
- SFX match weather and terrain across the whole environment.

Compatibility with the official WotC Tomb of Annihilation Foundry package, if you have purchased and installed it in the same world:
- Map notes on the Chult map link directly to the official journal pages and scenes.
- Encounter rolls will use the official adventure's wilderness encounter tables automatically.
